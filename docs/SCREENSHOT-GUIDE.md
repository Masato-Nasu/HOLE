No fabricated screenshots are provided.

1. Connect Nothing Phone (2) with USB debugging enabled.
2. Run `bash scripts/capture-screen.sh docs/screenshots/HOLE-home.png` while HOLE's initial settings view is on-screen.
3. Start the overlay in `50%` mode, switch to a non-sensitive app, and run `bash scripts/capture-screen.sh docs/screenshots/HOLE-50.png`.
4. Capture another image after using `CALIBRATE`, if suitable.
5. Film the physical phone from a second device to demonstrate the illusion; ordinary screenshot capture cannot demonstrate the actual alignment between phone edges and the environment.
6. Only then commit / add the genuine media to the repository.

Do not claim a computer-generated simulation is a capture of the running Android app.
