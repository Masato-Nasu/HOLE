# HOLE — スマートフォンを「穴」にする

スマートフォンの画面を、向こう側が見える穴のようにできないか。

そんな発想から、Androidアプリ「HOLE」を作りました。

HOLEは、スマートフォンの背面カメラで撮った映像を、ほかのアプリの上に半透明で重ねます。画面には、いま操作しているアプリと、スマートフォンの向こう側にある景色が同時に現れます。

標準は50%の重ね合わせです。カメラ映像を透かしたまま、画面の下にあるアプリを操作できます。

ただカメラの映像を重ねても、実際の景色と完全には一致しません。カメラは画面の中心にありませんし、カメラの画角と肉眼の見え方も違います。そこで、倍率と縦横の位置を手動で調整できるようにしました。

100%にすると、画面はほぼカメラ映像だけになります。ただし、Androidのセキュリティ上の制約で、このモードでは下のアプリへのタッチ操作はできません。

物理的に透明になるわけではありません。カメラとディスプレイを使って、スマートフォンという物体の存在を少し曖昧にする仕組みです。

ふだんは世界を見るための画面を、世界を通すための画面にする。

それがHOLEです。
