# HOLE — Transparent Phone P0.1

First public prototype based on the version tested on a Nothing Phone (2) in September 2026.

- Rear camera preview over other apps
- 50% default opacity; 10–79% adjustable touch-through mode
- 100% optical HOLE VIEW (view-only on Android 12+)
- Scale + X/Y optical calibration
- Persistent foreground-service notification with STOP
- No Internet access, recordings, or camera image saving

**Download:** `HOLE-v0.1.0-debug.apk` (Android 8+).

**Important:** This is a **debug-signed test APK**, built with GitHub Actions, not a production-signed release. On an update from a separately built debug APK, certificate mismatches may require uninstalling the old app first (which removes its saved calibration). The phone does not become physically transparent. Alignment is approximate and depends on viewing distance.
